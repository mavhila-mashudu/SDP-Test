# Repo Analysis Tool

A web dashboard for measuring change, churn, ownership, and activity across Git repository history.

## Requirements

- Python 3.10 or newer
- Git 2.30 or newer

## Run

```bash
git clone <public-repository-url>
cd <repository-directory>
chmod +x start.sh
./start.sh
```

Open <http://127.0.0.1:5000>.

## Current status

The runnable application skeleton is in place. Repository ingestion, metrics, filtering, validation, and complete usage documentation are implemented in subsequent project stages.
